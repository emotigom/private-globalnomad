## 프로젝트

코드잇 6기 개인 연습작품. 부트캠프 제공 샘플 시안을 기반으로 구현했다.

## 기술

- Next.js 14
- React 18
- Tailwind CSS

공개 열람과 포트폴리오 검토 목적의 저장소다. 코드 재사용·수정·배포 권한은 부여하지 않는다.
